# Release package contents / 发布包内容

This source package includes application source, public assets, scripts, lockfile, bilingual user documentation, selected UI screenshots and development/architecture notes. It excludes node_modules, dist, local agent settings, temporary browser profiles, raw verification traces/screenshots and old backup folders. No user artwork or camera recordings are included.

本源码包包含应用源码、公开资源、脚本、依赖锁文件、中英说明、精选界面截图及开发/架构记录。排除 node_modules、dist、本地 Agent 配置、临时浏览器目录、原始验证轨迹/截图与旧备份目录。包内不包含用户作品或摄像头录制。

The included screenshots are isolated simulated-browser captures; see SCREENSHOTS.md. This package is a source archive, not a signed installer or hosted release. The repository currently has no root-level LICENSE file.

截图均为隔离浏览器模拟输入，详见 SCREENSHOTS.md。本包是源码压缩包，不是签名安装程序或托管发行版。当前项目尚无根许可证文件。
