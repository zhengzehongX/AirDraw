# AirDraw 用户指南（发布版）

AirDraw 提供三个共享同一工程的创作空间：平面画布、三维笔迹与模型操控。当前应用不包含旧版 PlayLab 玩具。完整历史说明见根目录 USER_GUIDE.md。

## 开始前
1. 使用较新的 Chromium 浏览器，通过 localhost 或 HTTPS 打开。
2. 选择“开始体验”查看粒子 Hello，再明确选择“进入创作”。
3. 选择工作模式后按浏览器提示授权摄像头，等待手势状态就绪。
4. 摄像头预览可显示手部骨骼用于诊断；正常使用时可以收起。
5. 将手保持在镜头内。食指指向，拇指与食指捏合用于确认。

## 平面绘画
在 Canvas Draw 中捏合并移动完成笔画，松开结束。工具区提供钢笔、马克笔、荧光笔和橡皮擦，以及颜色、粗细、撤销、重做、清空和背景选项。白色、深色、透明背景作用于画布。支持 PNG 与 SVG 导出。

## 三维绘画
在 Spatial Draw 中捏合移动绘制有厚度的 3D 轨迹。地面网格与原点坐标轴帮助理解空间方向。工具区可以调整笔迹外观与材质。

## 模型操控
- **单手对象操作**：选择 Move、Rotate 或 Scale，指向对象并捏合保持；松开释放。短暂保持 V 手势可循环变换工具。
- **双手世界导航**：双手同时捏合，开合控制视图缩放，中点移动用于平移，两手连线转动或上下移动用于调整视角。
- **导入模型**：支持 GLB 和 glTF。glTF 的外部 BIN 与贴图需一并选择。
- **触控水面**：在水面范围内捏合并轻滑可看到波纹；这是视觉近似，不是物理接触传感器。

## 工程与备份
使用工程菜单新建、保存、复制、重命名、打开或删除项目。编辑暂停后自动保存。工程保存在浏览器本地；清除站点数据会移除本地项目。请导出 AirDraw JSON 备份重要作品。

## 导出
平面画布支持 PNG/SVG；创作画面支持 PNG/WebM；三维对象支持 GLB；整个工程支持 JSON。默认摄像头预览不包含在创作导出画面中。

## 当前边界
- 摄像头授权与系统文件选择器需要普通系统输入。
- 语音识别行为取决于浏览器，不能默认视为离线处理。
- 自动化与合成手测试不能代替真实摄像头和真人操作。
- 已知真人反馈：手静止后指针与笔迹仍可能偏移；精细创作前请检查，需要时导出输入诊断。
- 发布截图是隔离浏览器下的模拟输入截图，不是实机演示。
